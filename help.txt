Tedi - Text Editor

Build & Run:
  make
  ./build/tedi [file]

Keys:
  CTRL-s        Save
  CTRL-f        Find (ESC to cancel)
  CTRL-q        Quit (press '!' to discard unsaved changes)

  Enter         New line
  Backspace     Delete previous character
  Delete        Delete character under cursor

  Arrow keys    Move cursor
  Page Up/Down  Scroll
  Home/End      Start/end of line

  CTRL-h        Delete previous character (alias for Backspace)
  CTRL-t        Load theme (hardcoded to test.colorscheme)
